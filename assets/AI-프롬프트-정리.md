# AI 프롬프트 정리

## MotionSites AI

- 사이트: [MotionSites AI — Playful Idea](https://motionsites.ai/?prompt=playful-idea)
- 프롬프트 원문: [playful-idea.txt](./playful-idea.txt)
- 설명: `playful-idea.txt`의 내용은 위 MotionSites AI 사이트에서 사용할 프롬프트이다.
- 목적: 라벤더 캐릭터 영상이 배경으로 들어간 크리에이티브 스튜디오 푸터 페이지를 React·TypeScript·CSS로 재현한다.
- 비고: 원문에는 레이아웃, 문구, 폰트, 색상, 영상, 마우스 인터랙션, 모바일 동작 및 소스 코드가 포함되어 있다.

## Playful Cat

- 프롬프트 원문: [playful-cat.txt](./playful-cat.txt)
- 설명: 실제 갈색 태비, 흰 고양이, 주황색·흰색 태비 사진을 참고한 데스크톱 전용 토큰 인증 화면 프롬프트이다.
- 화면 구도: 위에서 바닥을 내려다보는 탑다운 시점으로, 왼쪽 약 1/3은 비우고 오른쪽 약 2/3에 고양이 세 마리를 균형 있게 배치한다.
- 표현 방식: 실사나 3D 인형이 아닌 부드러운 일본 애니메이션 영화풍이며, 세 고양이의 몸·얼굴·눈 크기와 화면상 비중을 비슷하게 맞춘다.
- 배경과 조명: 조용한 회색·회갈색 바닥에 왼쪽 위에서 들어오는 넓고 은은한 자연광을 사용한다. 강한 햇빛 줄무늬와 뿌연 효과는 사용하지 않는다.
- 시선 인터랙션: 작은 파란 생선 커서를 여섯 눈동자가 실시간으로 따라본다. 생선이 화면 끝에 있으면 눈동자는 자연스러운 최대 범위에서 멈춘다.
- 꼬리 모션: 세 꼬리를 별도 레이어로 분리하고 서로 다른 속도, 회전 폭, 시작 시점으로 천천히 움직인다.
- 화면 요소: 왼쪽 위 반투명 유리 자물쇠와 문구·placeholder·버튼 없는 토큰 입력창을 사용한다.
- 인증 방식: 마지막 입력 후 약 800ms가 지나면 자동 검증하며, 실패 시 문구 없이 입력값을 비우고 성공 시 기존 인증 후 화면으로 전환한다.
- 범위: 모바일 구성은 이번 버전에서 제외한다.
